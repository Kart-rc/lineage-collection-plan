**What this unblocks.** Wave 0 can start now. The oracle exists as fixtures, the twin runs in this sandbox, every component has a work package and a test ([doc 09](09-component-build-sheet.md)), and the policy, people and money questions are answered.

**What changed in the plan.** Four decisions change the plan, not only fill it in:

- **D7.** Phase 1 builds service edges from traces, not gateway logs.
- **D8.** Kafka hops are joined on the topic, not on trace links.
- **D23.** The twin runs a separate lineage platform beside the demo, with Neo4j standing in for Neptune.
- **D30.** Some lineage exists only while a flag is on. Edges carry a condition, and a flag change event alone can change the graph.

The first two come from reading the demo's code and its maintainers' own notes. They, and D30, were confirmed by the capture run on 27 November (doc 09).
