One field through the slice

The same change at this phase: PR #482 renames merchant_category_code to mcc

The schema registry's BACKWARD check passes this change at every phase, because removing a field and adding one with a default are both allowed. Only the map knows who still reads the old name.

One edge, several witnesses

No collector writes the graph. Each one reports what it saw, the resolver turns every name into one URN, and the evidence for an edge adds up. An edge seen by three independent sources scores higher than one seen by a single source.

How an edge earns trust, and loses it

Edges are never just present or absent. They move between states as evidence arrives and expires, and the two queries that matter read different states: impact analysis walks probable and above, root-cause analysis walks confirmed and above first.
